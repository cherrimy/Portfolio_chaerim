    AI 증적 검토 비동기 처리 및 상태 관리 구현

    수탁사가 제출한 보안 증적자료를 AI가 검토해 일치·불일치·미흡으로 보여 주는 기능입니다.
    참여 Laravel Queue 처리 구조의 초기 설계는 이사님이 제시 · 이후 UI 기획, 프론트엔드·백엔드 구현은 직접 담당
    문제 원인
    • 검토를 건별로 실행해야 했고, 새로고침하거나 페이지·탭을 이동하면 진행 중인 검토 작업이 끊기는 문제가 있었습니다.
    • 여러 증적자료를 한 번에 검토할 수 있어야 했고, 완료 여부를 실시간으로 확인해 사용자에게 알릴 수 있는 구조가 필요했습니다.
    해결 과정
    • Laravel Queue와 Job을 활용해 여러 증적자료 검토를 백그라운드 Job으로 분리하고 비동기로 처리했습니다.
    • React polling으로 각 검토 작업의 진행 상태를 주기적으로 조회해, 새로고침이나 페이지·탭 이동 후에도 상태를 이어서 확인하고 완료 시 알림창을 표시했습니다.
    결과
    • 여러 증적자료 검토를 동시에 실행할 수 있게 되었고, 새로고침이나 페이지·탭 이동 중에도 검토가 중단되지 않도록 개선했습니다.
    • 진행 상태와 실패 사유를 즉시 확인할 수 있었으며, 완료 시 실시간 팝업 알림으로 결과 확인 흐름을 개선했습니다.

    OCR·AI 하이브리드 기반 개인정보 마스킹

    증적으로 올린 이미지 속 개인정보를 AI가 찾아 자동으로 가려 주는 기능입니다.
    참여 기획부터 프론트·백엔드 구현까지 직접 담당
    문제 원인
    • AI는 개인정보 식별은 잘했지만, 마스킹에 필요한 정확한 좌표를 찾는 성능이 약했습니다.
    해결 과정
    • OCR은 좌표, AI는 식별을 맡는 하이브리드 방식으로 구현했습니다.
    • OCR이 놓친 항목만 AI가 2차로 식별하고 좌표를 보완하게 했습니다.
    결과
    • AI 단독 방식 대비 마스킹 대상 탐지율을 약 60%에서 약 90%로 개선했습니다.
    기술 상세 보기
    1. 역할 분리: OCR(Tesseract)은 텍스트와 좌표 추출, AI는 개인정보 식별을 맡습니다.
    2. OCR 전처리 후 Tesseract로 텍스트와 좌표를 추출합니다.
    3. AI가 개인정보를 판별하고, OCR 결과와 유사도로 매칭해 좌표를 가져옵니다.
    4. 매칭되지 않은 항목만 AI가 2차로 식별하고 좌표를 보완합니다.
    5. 유형별 검증과 중복 제어 후 마스킹 이미지와 좌표 목록을 반환합니다.

    • 중계서버가 외부 API를 대신 호출하도록 구현했습니다.
    • 노출 위험과 대안을 이사님께 공유하고, 제시된 구조 안에서 위험을 낮췄습니다.
    결과
    • 현장 변경 부담을 줄이면서 외부 API 연동을 구현했습니다.
    • 민감 정보의 전달·기록 범위를 줄였습니다.
    기술 상세 보기
    1. 전달 항목을 최소화하고 요청은 HMAC으로 검증합니다.
    2. AI 호출은 허용된 HTTPS 주소만 통과시킵니다.
    3. 로그에는 호스트·응답 코드·소요 시간만 남기고 프롬프트와 API 키는 기록하지 않습니다.
