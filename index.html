PROJECT 01 · AI & FULL-STACK

AI 문서 및
증적 검토 시스템

문서와 보안 증적을 검토하는 반복 업무를 AI 기반으로 지원하도록 기능을 기획하고 구현했습니다.

기간 2024.07 – 현재역할 기획 · 프론트엔드 · 백엔드

01 / DOCUMENT REVIEW

AI 문서 검토 기능 기획 및 개발

위수탁계약서의 주요 조항을 AI가 검토하고, 확인이 필요한 항목과 보완 사항을 제시하는 기능입니다.

  • 문서 유형별 필수 항목, 관련 법조항, 검토 유의사항을 정리해 검토 기준을 구성했습니다.
  • 문서 길이와 입력·출력 토큰량을 고려해 API 호출 방식을 조정했습니다.
  • 모델별 응답과 오답 패턴을 비교하며 프롬프트 및 호출 옵션을 반복 개선했습니다.
  • 문서 유형과 검토 항목별 테스트 케이스를 구성해 결과를 검증했습니다.
결과기존 포트폴리오 기준 검토 정확도 약 80~90% 수준

02 / ASYNC PROCESSING

AI 증적 검토 비동기 처리 및 상태 관리

여러 증적자료를 검토하는 동안 페이지 이동이나 새로고침이 있어도 작업을 이어서 확인할 수 있도록 처리 구조를 개선했습니다.

  • Laravel Job과 Queue를 활용해 증적 검토를 백그라운드 작업으로 분리했습니다.
  • React Polling으로 작업별 진행 상태를 주기적으로 조회하도록 구현했습니다.
  • 완료 여부와 실패 사유를 화면에서 확인하고, 완료 시 사용자에게 알림을 표시했습니다.
결과복수 검토 작업의 비동기 실행 및 진행 상태 확인 지원
TECH STACKPHP · Laravel · Queue / Job · React · JavaScript · AI API

  • 답변 처리 API에서 전달받은 다음 문항과 알림 정보를 화면에 연결했습니다.
결과복잡한 조건 분기를 하나의 점검 흐름에서 처리하도록 구현

반복적인 기업 및 사용자 등록 업무를 엑셀 기반 일괄 처리로 개선했습니다.
