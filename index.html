    온프레미스 전용 중계서버 구축 및 외부 API 호출 기능 구현

    문제온프레미스 환경에서는 메시지, Sentry, 이메일, AI 같은 외부 API를 WAS에서 직접 호출하기 어려웠고, 환경 변수를 추가할 때마다 현장 방문이 필요할 수 있었습니다.

    어려움온프레미스는 환경 변수를 추가할 때마다 현장 방문이 필요할 수 있어서, 중계서버의 환경 변수를 최소화해야 했습니다. 그렇다고 WAS가 필요한 정보를 payload로 매번 전달하면 민감 정보가 노출될 수 있어 보안상 위험했습니다.

    해결중계서버가 외부 API(메시지, Sentry, 이메일, AI)를 대신 호출하도록 구성했습니다. WAS가 정보를 payload로 매번 전달하면 민감 정보가 노출될 수 있어서, 이 보안 위험을 근거로 설명해 중계서버가 WAS의 env를 직접 조회해 쓰는 구조로 설계를 조정했습니다.

    결과환경 변수 추가와 현장 방문 부담을 줄이면서, 민감 정보를 payload로 보내지 않고도 외부 API 호출 기능을 제공했습니다.

    AI 이미지 개인정보 마스킹 기능 구현

    문제증적 이미지의 개인정보를 AI로 식별해 자동으로 마스킹해야 했습니다.

    어려움AI는 개인정보가 무엇인지는 잘 식별했지만, 마스킹에 필요한 정확한 좌표를 찾는 성능은 약했습니다.

    해결AI와 OCR을 결합한 하이브리드 방식으로 구현했습니다. Tesseract OCR이 개인정보를 1차로 식별하고 정확한 좌표를 잡으며, OCR이 놓친 항목은 AI API가 2차로 식별하고 좌표를 추출하도록 단계를 나눴습니다.

    결과AI 단독 방식 약 60% 대비 인식 정확도를 약 80%까지 개선했습니다.

    개발 단계 보기
    1. 입력 검증: 이미지와 파라미터 확인
    2. 임시 파일·메타 준비: 임시 디렉터리 생성, 이미지 크기 추출
    3. OCR 전처리: 리사이즈·그레이스케일·이진화, 흰 격자선 제거
    4. Tesseract OCR 실행: 언어·PSM 조합으로 후보 선택
    5. OCR 결과 후처리: 노이즈 필터링, 같은 줄의 인접 텍스트 결합
    6. AI 개인정보 식별: 이미지와 프롬프트, OCR 텍스트 힌트를 AI에 전달해 JSON으로 수신
    7. AI·OCR 매칭: 유사도 기반으로 좌표 매칭
    8. 미매칭 개인정보: AI가 좌표를 직접 추출
    9. 결과 통합·필터링: 유형별 유효성 검사, 중복·겹침 제어
    10. 마스킹 이미지 생성: 좌표를 픽셀 좌표로 변환해 박스와 유형 라벨 표시
    11. 응답 구성: 원본·마스킹 이미지, 좌표 목록, 처리 시간, 하이브리드 통계 반환
    12. 정리: 임시 파일 삭제, 예외 시 로깅과 표준 에러 응답

    해결CSV 양식 다운로드와 CSV 업로드 기능을 직접 제안하고 개발했습니다. ChatGPT 프롬프트에는 출력 형식을 고정하고 특수문자를 처리하는 규칙을 넣어 여러 번 보완했고, 양식과 지침은 ChatGPT 프로젝트에 저장해 두었습니다. 뉴스만 붙여 넣으면 양식에 맞는 CSV가 만들어지고, 관리자 페이지에 올리면 제목·내용·링크가 한 번에 등록됩니다.

    결과약 1시간 걸리던 업무를 약 10분으로 줄였고, CSV가 깨지지 않고 안정적으로 업로드되게 했습니다.
