PROJECT 01 · AI & FULL-STACK

AI 문서 및
증적 검토 시스템

문서와 보안 증적을 검토하는 반복 업무를 AI 기반으로 지원하도록 기능을 기획하고 구현했습니다.

기간 2024.07 – 현재역할 기획 · 프론트엔드 · 백엔드

01 / DOCUMENT REVIEW

AI 문서 검토 기능 기획 및 개발

위수탁계약서의 주요 조항을 AI가 검토하고, 확인이 필요한 항목과 보완 사항을 제시하는 기능입니다.

  • 문서 유형별 필수 항목, 관련 법조항, 검토 유의사항을 정리해 검토 기준을 구성했습니다.
  • HTML 파싱과 문서 단위 구조화로 입력 데이터를 전처리하고, 토큰량에 맞춰 API 호출 방식을 조정했습니다.
  • 모델별 응답과 오답 패턴을 비교하며 프롬프트 및 호출 옵션을 반복 개선했습니다.
  • 문서 유형과 검토 항목별 테스트 케이스를 구성해 결과를 검증했습니다.
핵심 구현계약서 유형과 검토 항목을 먼저 판별한 뒤, 선택 항목만 조항 검증 단계로 넘겼습니다.
준수 항목은 결과와 재호출 대상에서 제외해 중복 검토를 줄였습니다.
결과테스트 기준 검토 정확도를 기존 80%대에서 98%까지 개선

02 / ASYNC PROCESSING

AI 증적 검토 비동기 처리 및 상태 관리

여러 증적자료를 검토하는 동안 페이지 이동이나 새로고침이 있어도 작업을 이어서 확인할 수 있도록 처리 구조를 개선했습니다.

  • Laravel Job과 Queue를 활용해 증적 검토를 백그라운드 작업으로 분리했습니다.
  • React Polling으로 작업별 진행 상태를 주기적으로 조회하도록 구현했습니다.
  • 완료 여부와 실패 사유를 화면에서 확인하고, 완료 시 사용자에게 알림을 표시했습니다.
핵심 구현작업별 ID와 상태값으로 진행 중·완료·실패 상태를 분리했습니다.
화면은 작업 ID로 최신 상태를 조회해 결과를 이어서 확인할 수 있도록 했습니다.
결과새로고침이나 탭 이동 중에도 검토가 중단되지 않는 비동기 실행 구조 구현
TECH STACKPHP · Laravel · Queue / Job · React · JavaScript · OpenAI API · Claude API

PROJECT 03 · SECURITY

서비스 보안 및
개인정보 보호

서비스 보안 요구사항을 반영하고 개인정보 처리 과정의 안전성을 높이기 위한 기능 개선을 진행했습니다.

기간 2024.07 – 현재역할 기능 개발 · 취약점 개선

인증 강화 및 보안 취약점 개선

  • OTP 기반 2단계 인증 기능을 구현하고 인증·접근 관련 기능을 점검했습니다.
  • CSAP 지적 12건 중 실제 위험 10건을 수정하고, 오탐 2건은 근거를 정리해 소명했습니다.
  • 별도 모의해킹 점검에서 확인된 취약 8건을 조치하고 수정 결과를 다시 확인했습니다.
주요 조치OTP는 TOTP 기반으로 구현하고 인증 시크릿 저장, 발급 제한, 재인증 흐름을 점검했습니다.
모의해킹 항목은 XSS, 인증 우회, 인가 검증, 세션 만료 정책을 코드 기준으로 수정했습니다.

OCR·AI 하이브리드 개인정보 마스킹

문서 내 개인정보를 탐지하고 마스킹하는 과정에서 OCR과 AI 기반 처리를 결합했습니다.

  • OCR은 텍스트와 좌표 추출, AI는 개인정보 식별을 맡도록 역할을 분리했습니다.
  • OCR 결과와 AI 탐지 결과를 매칭해 좌표를 보완하고 마스킹 처리 흐름에 연결했습니다.
핵심 구현매칭이 어려운 항목은 2차 탐지로 분리하고, 유형 검증과 중복 좌표 제어를 적용했습니다.
탐지 결과와 좌표 품질을 함께 보정해 실제 마스킹 처리까지 연결했습니다.
결과마스킹 대상 탐지율을 약 60%에서 약 90% 수준으로 개선

온프레미스 환경 외부 API 중계 서버

외부 API에 직접 접근하기 어려운 온프레미스 환경을 고려해 중계 서버를 개발하고 연동 흐름을 구성했습니다.

  • 중계 서버가 메시지, 이메일, AI 등 외부 API 호출을 대신 처리하도록 구현했습니다.
  • 요청 전달 항목과 로그 기록 범위를 줄여 설정값과 민감 정보 노출 위험을 낮췄습니다.
결과현장 변경 부담을 줄이면서 외부 API 연동 구조를 안정화
